
# Flight Reservation System

## Aim
To implement a basic Flight Reservation System using searching and sorting algorithms in Python.

## Description
This project simulates a simple flight reservation system. Users can view available flights, search for a flight using its ID, sort flights by ticket price, book a flight, and view reservations.

## Algorithms Used

### 1. Linear Search
Linear Search is used to find a flight using its unique flight ID.

### 2. Bubble Sort
Bubble Sort arranges flights in ascending order of ticket price.

## Features
- Display available flights
- Search flights by ID
- Sort flights by ticket price
- Book a flight
- View booked reservations
- Menu-driven interface

## Technologies Used
- Python 3
- Lists and Dictionaries
- Linear Search
- Bubble Sort

## How to Run
1. Install Python 3.
2. Save the code as `main.py`.
3. Open a terminal in the project folder.
4. Run:

   `python main.py`

## Time Complexity
- Linear Search: O(n)
- Bubble Sort: O(n^2)
- Display Flights: O(n)

Here, n is the number of available flights.

## Limitations
This is an educational simulation. Flight data is stored in memory and reservations are not saved after the program exits. It does not connect to real airlines or process payments.

## Conclusion
This project demonstrates how searching and sorting algorithms can be applied to a basic flight reservation system.
